# איקס עיגול · זירת הקרח

A Hebrew tic-tac-toe game you can open in a browser. Play against an unbeatable computer, or pass the device for two players.

## Run

Open `index.html` in a browser. No install or build step.

## Play

- You are **עיגול** (circle). The computer, or the second player, is **איקס** (cross).
- Circles always move first.
- **נגד מחשב** — the computer replies with minimax and never loses.
- **שני שחקנים** — two people share the same board.
- **מהלך אחורה** undoes the last move (and the computer’s reply in AI mode).
- **סיבוב חדש** clears the board and keeps the score. Switching modes resets the score.

Wins, draws, and the current turn are shown above the board. A line is drawn through three in a row.
